# Object-Oriented Programming — Registration System

A Java desktop coursework project built with Swing and the NetBeans GUI Builder. It contains a registration-oriented interface with user fields, administrative forms, and NetBeans/Ant project configuration.

## Technology

- Java
- Swing
- NetBeans GUI Builder
- Ant build files

## Run

1. Open the `Registration` project in NetBeans.
2. Allow NetBeans to load the generated form and Ant configuration.
3. Select the available main class and choose **Run Project**.

This repository preserves coursework and IDE-generated desktop form files. It is not presented as a production identity or account-management system.
