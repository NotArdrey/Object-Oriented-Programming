# Java OOP Projects

This repository contains multiple projects demonstrating Object-Oriented Programming (OOP) concepts in Java, including:

1. **Registration System:** A system for user registration and management, showcasing encapsulation and data handling.
2. **Banking System:** A simulation of banking operations, illustrating inheritance, polymorphism, and transaction management.
3. **Zoo Management System:** A system to manage zoo animals and their care, highlighting abstraction and organization of complex data.

Each project emphasizes key OOP principles and provides practical examples of how to implement them.
